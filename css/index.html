Seletores

Uma parte importante ao aplicar o CSS é selecionar qual elemento/tag queremos aplicar o estilo. Os Seletores servem como uma forma de "busca" por um ou mais elementos específicos em meio a todas tags do documento HTML.

> <

Tipos de seletores

  • Tag
  • Id
  • Classe
  • Outros
> <

Tag

li { color:red; }
<ul>
    <li>Sol</li>
    <li>Mercúrio</li>
    <li>Vênus</li>
    <li>Terra</li>
    <li>Marte</li>
    <li>Plutão</li>
</ul>
> <

Id

#terra { color:red; }
<ul>
    <li>Sol</li>
    <li>Mercúrio</li>
    <li>Vênus</li>
    <li id='terra'>Terra</li>
    <li>Marte</li>
    <li>Plutão</li>
</ul>
> <

Classe

.planeta { color:red; }
<ul>
    <li class='estrela'>Sol</li>
    <li class='planeta'>Mercúrio</li>
    <li class='planeta'>Vênus</li>
    <li class='planeta' id='terra'>Terra</li>
    <li class='planeta'>Marte</li>
    <li class='nao-eh-planeta😞'>Plutão</li>
</ul>
> <

Posicionamento block

div.block { 
  width: 100px;
  height: 100px;
  background: red;
  /* display: block; *//* Aqui eu não preciso do display: block; pq a div já tem comportamento block*/
  margin: 10px;
}
> <

Posicionamento inline

.inline-block { 
  width: 100px;
  height: 100px;
  background: red;
  display: inline-block;
  margin: 10px;
}

* O inline sozinho não aceita que se coloque um tamanho pré-definido, então coloquei inline -block para poder adicionar um tamanho aos quadrados

> <
